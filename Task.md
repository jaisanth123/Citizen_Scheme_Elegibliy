Background Misinformation spreads quickly through messaging apps and social media. Verifying a claim requires searching multiple sources and weighing evidence, which most people do not have time to do. Objective Build a pipeline that extracts factual claims from text, gathers evidence, delivers a reasoned verdict with sources, and compiles a daily digest of verified news. Target users: Journalists, students, general public, media-literacy educators. Sample User Queries • Is it true that drinking hot water cures viral infections? • Fact-check this forwarded message: [pasted text]. • Give me today's verified technology news digest. • Show me the claims I checked this week. Components Component Specification MCP server tools RAG knowledge base save_digest: Saves a compiled digest with date and topic. get_saved_claims: Returns previously checked claims and their verdicts. export_markdown: Exports a digest or fact-check report to a Markdown file. Archive of previously verified fact-checks; list of trusted sources and their credibility notes. Tavily web search Primary evidence gathering from live news and authoritative websites (core to this task). Agent Design (LangGraph) Agent / Node Responsibility Claim Extractor Evidence Retriever Verdict Judge Splits input text into individual, checkable factual claims. Searches Tavily and the RAG archive for supporting and contradicting evidence (ReAct loop). Weighs evidence and assigns a verdict: True, False, Misleading or Unverifiable. Critic Digest Writer Reviews the verdict for weak evidence or bias and sends it back if needed (reflection). Compiles verdicts or daily news into a digest and saves it via MCP. Orchestration flow: Sequential pipeline with a reflection loop: the Critic can return a verdict to the Evidence Retriever for more evidence, up to a fixed number of rounds. Expected Output Per-claim verdicts with a confidence level, summarised evidence and linked sources; a daily digest exported as Markdown. Guardrails and Constraints Must say "Unverifiable" rather than guess; must present evidence from both sides; must avoid political bias and cite every source. Suggested data sources: Google Fact Check Tools API or published fact-check articles for the archive; Tavily for live search. Optional enhancements: Evaluate verdict accuracy on a labelled set of known claims
